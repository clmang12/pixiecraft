# PixieCraft

A 3D voxel sandbox game that runs in the browser: magical biomes, friendly creatures, enemies,
bosses, a fairytale castle, nightly fireworks, procedural music and online multiplayer.

Open `index.html` to play, or visit the GitHub Pages link for this repository.

**Online play:** one player clicks *Host a game* and shares the 5-letter room code; friends open
the same link, type the code and click *Join a game*.
